# Flight Search Engine Skill

## Directives
- **Filters**: Enforce maximum stops (0 for non-stop, 1 for international long-haul).
- **Price Benchmarking**: Compare fares against typical historical averages for season.
- **Deep Links**: Always generate clickable reservation URLs for the user's booking convenience.
