# Liquid Glass Travel UI Skill

## Directives
- Dark obsidian base (`#0A0E17`) with vibrant destination accents (Azure, Emerald, Sunset Gold).
- Translucent frosted glass containers (`backdrop-blur-xl`, `bg-white/5`, `border-white/10`).
- RTL native support (`dir="rtl"`) with dedicated Hebrew typography classes.
