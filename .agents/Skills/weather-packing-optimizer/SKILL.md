# Weather & Smart Packing Optimizer Skill

## Directives
- Calculate average high/low temperatures (°C), precipitation risk, and UV index for trip dates.
- Categorize packing items into: Essential Documents, Weather-Appropriate Attire, Tech & Adapters, Health & First Aid, and Activity Gear (e.g. swim, hike).
- Provide electrical plug socket types (e.g., Type C/F/G) and standard voltage for the target country.
